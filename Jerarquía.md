# MODELO JERÁRQUICO DE AUDITORÍA MOP PROFEDET

## PROPÓSITO

Este modelo de auditoría tiene como finalidad revisar el Manual de Organización y Procesos de manera secuencial, estructurada y acumulativa.

Está prohibido auditar procedimientos completos en una sola revisión.

La auditoría se realizará por bloques documentales.

No podrá avanzarse a un nivel superior sin que el nivel anterior quede concluido.

# METODOLOGÍA DE TRABAJO

El auditor deberá:

1. Localizar todos los procedimientos.

2. Identificar el apartado correspondiente.

3. Revisar exclusivamente ese apartado.

4. Comparar contra:

- Misión institucional.
- Visión institucional.
- Objetivos institucionales.
- Funciones del área.
- Reglamento PROFEDET.
- Guía Técnica.
- Soporte Verificador.

5. Emitir observaciones.

6. Proponer texto corregido.

7. Continuar con el siguiente procedimiento.

No se revisarán actividades, políticas ni formatos cuando la auditoría se encuentre revisando objetivos.
